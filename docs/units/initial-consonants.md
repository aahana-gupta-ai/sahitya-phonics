# Initial consonants

This unit contains ten new example lessons for b, c, d, f, g, h, j, l, m, n. Lesson JSON files are under `data/lessons/`.

## Teaching workflow

Model pronunciation, read examples with the learner, invite a short practice response, and use the word in context. Allow rest and avoid interpreting a practice error as a diagnosis.

## Adaptation

Choose locally familiar vocabulary and review differences in English accents. Complex patterns may require prerequisite teaching. This sequence has not been evaluated in schools and does not establish the original programme's reach or outcomes.
