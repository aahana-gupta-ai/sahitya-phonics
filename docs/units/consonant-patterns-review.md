# Review: Consonant digraphs and trigraphs

Review targets: sh, ch, th, wh, ck, ng, qu, ph, tch, dge.

1. Ask an educator to check vocabulary and pronunciation.
2. Observe whether the learner is comfortable identifying the written patterns.
3. Revisit familiar examples before introducing harder vocabulary.
4. Record observations as support needs, without clinical conclusions.
5. Keep practice quiz accuracy separate from broad reading ability.

An unanswered item remains unobserved. Letter counts do not represent phoneme counts.
